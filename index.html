Massing Studio browser-based plan & extrusion tool
Quick Reference
  • Draw: pick a tool, click in the plan view
  • Polygon / Curve: click each point, Enter / double-click / click near start to close
  • Select: Shift+click or drag a box to select several; drag round handles to edit points
  • Extrude: set a height in Properties, or use Push/Pull in the 3D view — drag the top face for height, any side wall to move just that wall
  • Levels: add levels to stack floors; "Stack copy on top" in Properties; Alt+drag a volume in 3D to lift it
  • Measure: Dimension (D) in plan or on the 3D model, Area (A) in plan
  • Boolean: select two volumes → Intersect / Union / Subtract in Properties
  • Import: .obj as a 3D reference, .dxf as editable shapes, or an image to trace over
  • Copy / Cut / Paste: Ctrl+C / Ctrl+X / Ctrl+V, or the toolbar menu next to Undo/Redo
  • Pan: space+drag or middle-mouse · Zoom: scroll
  • Orbit (3D): left-drag · Pan: right-drag
